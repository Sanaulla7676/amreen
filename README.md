# Amreen's Academy — Multi-page website

This is an editable, multi-page HTML/CSS/JavaScript website using the academy's midnight navy, ivory and burgundy identity.

## Pages included
- `index.html` — Home
- `about.html` — About the academy
- `courses.html` — Course overview
- `professional-makeup.html` — Professional Makeup Artistry
- `skin-aesthetics.html` — Skin & Aesthetics
- `hair-styling.html` — Hair Styling
- `bridal-artistry.html` — Bridal Artistry
- `45-day-course.html` — Featured 40-Day Beauty & Makeup Course
- `faculty.html` — Faculty and learning approach
- `student-success.html` — Practice gallery
- `blog.html` — Beauty learning notes
- `faqs.html` — Frequently asked questions
- `contact.html` — Contact, map and WhatsApp enquiry

## Motion and interactions
- Hero title “Creativity” rises into view from below.
- Hero portrait, phrase and copy reveal in sequence.
- Animated ambient lighting and shimmer details.
- Scroll progress indicator and staggered scroll reveals.
- Card depth/tilt and hover motion.
- Responsive mobile navigation.
- Native FAQ accordions.
- Course carousel controls on the homepage.
- Reduced-motion accessibility support.
- Contact form prepares an enquiry in WhatsApp.

## Run locally on Windows
1. Extract the project ZIP.
2. Double-click `RUN_LOCAL.bat`.
3. Keep the terminal window open and use the local URL shown in the browser (usually `http://127.0.0.1:8000`).
4. Press Ctrl+C in the terminal to stop the local preview.

Alternatively, open PowerShell in this folder and run:
```powershell
python run_local.py
```

Python 3 is required for the included local preview launcher. No Node packages or build tools are required.
